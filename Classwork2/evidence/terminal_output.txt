===== 04_errors.py =====
1. Normal request:
  OK: sunt aut facere repellat provident occaecati excepturi optio reprehenderit

2. Missing resource:
  Server responded: True | status: 404 | ok: False
  404 - server responded but resource not found

3. Timeout (server waits 5s, we only wait 2s):
  Timeout after 2s

4. Rate limit (429):
  429 - attempt 1, waiting 1s
  429 - attempt 2, waiting 2s
  Gave up after 2 attempts

5. Server error (500):
  500 - attempt 1, waiting 1s
  500 - attempt 2, waiting 2s
  Gave up after 2 attempts

6. Network error (domain doesn't exist):
  Network error, could not connect

Program finished without crashing
