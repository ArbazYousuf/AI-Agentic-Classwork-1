Training vs Inference:
Training is when the model learns from labelled data (fit). It builds the
vocabulary and learns the weights. Inference is when we use the trained model
to predict labels for new text it has never seen (predict). No learning happens there.

Part 2: Text Preprocessing
------------------------------------------------------------
Cleaned sentences:
'   Hello,   WORLD!!  How are   you?  ' -> 'hello world how are you'
"Machine\tLearning\nis   AMAZING... isn't it?" -> 'machine learning is amazing isnt it'
'Email me at: Support@Example.COM, ASAP!!!' -> 'email me at supportexamplecom asap'
'Price: $49.99 (20% OFF) - limited time!' -> 'price 4999 20 off limited time'
'Already clean text' -> 'already clean text'

Only whitespace removed:
'   Hello,   WORLD!!  How are   you?  ' -> 'Hello, WORLD!! How are you?'
"Machine\tLearning\nis   AMAZING... isn't it?" -> "Machine Learning is AMAZING... isn't it?"

Why preprocessing is useful:
- 'Hello', 'hello' and 'hello!' become the same word, so the model doesn't count them separately
- vocabulary gets smaller which helps when the dataset is small
- extra spaces and symbols are mostly noise
- but don't over clean, e.g. 'US' and 'us' mean different things

Special tokens: [CLS] is added at the start (used for classification), [SEP] at the end
or between two sentences, [PAD] for padding, [UNK] for unknown and [MASK] for masked words.
Subword tokenization breaks rare words into smaller known pieces so the vocab stays
small but can still handle any word. BERT uses ## for continuation pieces, GPT-2 uses
BPE and marks spaces with G, so both give different counts.
